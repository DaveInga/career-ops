Payments · Stripe Connect

Easy to pay. Easier to get paid.

Buyers check out in one tap. Sellers onboard once with Stripe Connect and money lands in their bank automatically — the platform never holds anyone's funds.

  1. One-tap checkout

    Card, Apple Pay, or Google Pay via Stripe. Your payment method is saved after the first purchase — every beat after that is a single tap.

  2. Wallet credits for micro-purchases

    Sub-$1 card charges get eaten by processing fees. Top up a wallet once ($5–$20) and spend it in $0.99 increments — creators keep more of every sale.

  3. Instant delivery

    Files unlock in your library the moment payment settles. Re-download anytime; licenses are stored as signed PDFs on your account.

HOW IT WORKS UNDER THE HOOD

  1. 1
    Browser asks the API for an upload slot; server returns a presigned PUT URL scoped to one object key.
  2. 2
    File goes directly to Vultr Object Storage (ewr1.vultrobjects.com, S3-compatible) — multipart for anything over 100 MB.
  3. 3
    Masters land in a private bucket (crate-masters); nothing is publicly readable.
  4. 4
    A worker renders a tagged 128kbps preview + waveform JSON into the public CDN bucket (crate-previews).
  5. 5
    After purchase, buyers get short-lived presigned GET links to the untagged masters.

For the build team

The stack behind the mock

🔐 Auth

Passwordless email magic links + Google OAuth 2.0 (OpenID Connect). One user record, multiple linked identities; JWT session cookies. Drop-in via Auth.js, Clerk, or Supabase Auth.

💸 Payments

Stripe Connect Express accounts for sellers. Purchases are destination charges with a 10% application_fee_amount; wallet top-ups use PaymentIntents and a ledger table for $0.99 spends. Daily automatic payouts.

🗄️ Storage

Vultr Object Storage (S3-compatible API — works with any AWS SDK, endpoint ewr1.vultrobjects.com). Presigned PUT for uploads, multipart for large files, private masters bucket + public previews bucket, presigned GET for delivery.
